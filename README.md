#  HANDPILOT

###  Launch HandPilot

 run:
 
```bash
git clone https://github.com/tuktukiaansh-cyber/HandPilot-1.0.git
cd HandPilot
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```
in terminal!!
